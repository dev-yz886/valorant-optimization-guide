# 《无畏契约》微秒级输入延迟压缩指南：NVIDIA Reflex 与显示器刷新率锁帧（Minus-3 法则）实操

**核心排查结论：** 《无畏契约》拉枪粘滞根因是渲染队列积压。显卡开Reflex On+Boost、预渲染设为1并按刷新率减3帧锁定即可降至7.5ms。

---

## 一、 底层机理排查与关键参数对比表

| 调优方案组合 | 端到端系统输入延迟 | CPU 提交缓冲队列 | 跟枪微调手感 | 电竞选手推荐度 |
| --- | --- | --- | --- | --- |
| 游戏内不锁帧 + Reflex 关 | 28.5ms ~ 36.2ms | 积压 2~3 帧（GPU 99%满载阻塞） | 拉枪有明显拖手感 | 不推荐 |
| Reflex 开启 (On) + 不锁帧 | 15.4ms ~ 19.8ms | 动态限制为 1 帧 | 操作基本顺手，偶有波动 | 三星 |
| Reflex On+Boost + Minus-3 锁帧 | 7.5ms ~ 9.2ms | 队列彻底排空，时钟强制拉满 | 指哪打哪，微秒级瞬间索敌 | 五星（职业电竞标准） |

> [!WARNING]
> **安全提示：** 若使用第三方调优软件（如 RTSS / RivaTuner）进行全局锁帧，请务必在《无畏契约》中关闭其 OSD 状态显示注入功能，防止 Vanguard 将其未签名内存钩子误判为违规注入。

## 二、 核心排查与实操修复步骤

### 1. 步骤 1：NVIDIA 控制面板配置全局低延迟流水线
桌面空白处右键打开【NVIDIA 控制面板】->【管理 3D 设置】->【程序设置】，选中 VALORANT：

```cmd
1. 低延迟模式 (Low Latency Mode): 超高 (Ultra)
2. 最大预渲染帧数 (Max Pre-Rendered Frames): 1
3. 电源管理模式: 最高性能优先
4. 垂直同步: 强制关闭 (Off)
```

### 2. 步骤 2：驱动面板精准配置 Minus-3 锁帧上限
在控制面板中找到【最大帧速率 (Max Frame Rate)】，根据显示器物理刷新率按减 3 原则设定，防止 GPU 冲入 99% 负载触发排队：

```cmd
360Hz 电竞屏 -> 锁定为 355 FPS
240Hz 电竞屏 -> 锁定为 237 FPS
165Hz 电竞屏 -> 锁定为 162 FPS
144Hz 电竞屏 -> 锁定为 141 FPS
```

### 3. 步骤 3：游戏内部启用 Reflex 增强与纯净全屏
进入游戏设置 -> 画面设置：
1. 【显示模式】务必锁定为【全屏】；
2. 【限制帧率】所有开关全部设为【关闭】（统一由显卡驱动层硬锁）；
3. 【NVIDIA Reflex 低延迟】选项强制选择为【开启 + 增强 (On + Boost)】。

```cmd
验证指标：在游戏内打开【统计数据】-> 勾选【CPU 帧时间】与【GPU 帧时间】，两条曲线呈高度平行的笔直线条即为调优成功。
```

## 三、 常见故障排查与深度 FAQ

#### Q: 为什么帧率不锁上限（如跑到 500FPS）输入延迟反而不如锁 237FPS？
> **A:** 当显卡占用率达到 99% 极限制时，CPU 提交下一帧渲染指令的速度超过了 GPU 消耗速度，驱动被迫开启 FIFO 渲染队列缓冲，累积的排队帧数正是产生输入粘滞感的物理元凶。

#### Q: AMD 显卡用户如何对齐此项参数？
> **A:** AMD 用户可在驱动中开启【Radeon Anti-Lag】，并通过【Radeon Chill】设置相同的 Min/Max 锁帧数值达到相同低延迟效果。
